# jsw_keshev 완성본 시연 순서와 정리 (2026-10-27)

이 문서는 앱 이름 `jsw_keshev`(`student/appearance.json`, 기본 이름은 케셰브)의 현재 상태를 정리합니다. 확인하지 않은 것은 된다고 쓰지 않고 "미확인"으로 둡니다. 화면 틀은 관제 대시보드형(위 상태 카드 4개, 아래 추이와 기록)이고, 포장 형태는 기본 포장(`npm run package-app` 결과와 바로가기)입니다.

## 1. 제공 기능과 내가 만든 기능

| 구분 | 내용 | 위치 |
|---|---|---|
| 제공 | PC 상태 조회 `GET /api/pc/status`(CPU·메모리·디스크·네트워크·방화벽·Windows 경고·오류), 제공 카드 「내 PC 상태」, 연결 모드 전달, 계정·AI 연결 절차, 보안 기록·업무 앱 화면 | `src/pc-status.mjs`, `public/` (시작 틀 그대로) |
| 내가 만듦 | 핵심 3가지 안내, 카드 4개(CPU·메모리·디스크·SDP 연결), 「PC 상태 조회/다시 조회」와 대기 표시, 최근 12회 추이(직전 대비 pp), PC 관찰 근거 모음과 한계, 항목별 실패 이유와 다음 할 일 | `student/extension.mjs` (`renderStatus`) |
| 내가 만듦 | 앱 이름 `jsw_keshev`, 카드 배치 `student-first` | `student/appearance.json` |

제공 파일 5개(`public/index.html`, `public/style.css`, `public/pc-status-view.mjs`, `src/pc-status.mjs`, `src/server.mjs`)는 시작 틀 버전과 SHA-256이 일치하게 되돌렸습니다. 설치형 앱에 반영되는 범위가 학생 영역과 꾸밈이기 때문입니다.

## 2. 핵심 기능 3가지와 시연 순서

핵심 3가지: ① 내 PC 점검 ② 변화 추이 비교 ③ PC 관찰 근거 모음.

1. `node src/server.mjs`(또는 `start-alekov.ps1`)로 켜고 `http://127.0.0.1:5189/`를 엽니다. 탭 제목 「jsw_keshev · ZTNA & XDR」를 확인합니다.
2. 보호 현황의 「학생 상태·알림 표시」에서 핵심 3가지와 표시 구분 문구를 보여 줍니다.
3. 「PC 상태 조회」: CPU·메모리·디스크가 「실측」과 측정 시각으로 나옵니다. 「SDP 연결」은 「SDP 미연결」(정상)입니다.
4. 「다시 조회」: 추이 표에 직전 대비 pp가 생깁니다.
5. 근거 모음: 네트워크·방화벽·Windows 경고·오류 건수와 "이것만으로 말할 수 없는 것"을 보여 줍니다. 건수는 공격 탐지가 아닙니다.
6. 키보드만으로 Tab 이동과 Enter로 조회합니다.

## 3. 아직 안 되거나 확인 불가로 남은 한계

| 한계 | 내용 |
|---|---|
| 서비스 연결·사용량·비용 | 구현하지 않음(미구현). 외부 서비스 연동 없음 |
| SDP 연결 | 「SDP 미연결」은 `-SdpHostConfig` 없는 기본 실행의 정상 표시이며 학생 준비 항목이 아닙니다. 실제 SDP 조회 결과는 이 앱에서 확인하지 않았습니다 |
| 측정 시각 | 제공 서버가 항목별 시각을 주지 않아 PC 조회 한 번의 시각만 표시합니다 |
| 추이 | 현재 브라우저 화면을 연 동안만 보관하며 새로고침하면 사라집니다. 일부만 읽은 회차는 넣지 않습니다 |
| 관리자 권한 | 쓰지 않습니다. 권한이 필요한 항목은 `확인 불가`와 이유로 표시합니다. 실제로 권한 오류가 난 사례는 이 PC에서 겪지 못했습니다 |
| 최근 보안 기록 | 대시보드에는 두지 않고 제공 「보안 기록」 탭으로 안내합니다 |
| 설치형 앱 | 이 PC에 승인 실행 host와 runtime이 없어 포장·설치·바로가기를 하지 못했습니다(미확인). `PROVIDED_RUNTIME_NOT_INSTALLED`가 예상되며 담당자 준비 항목으로 남기고 `--app-only-v1`로 우회하지 않습니다 |
| 아이콘 | 승인된 PNG 아이콘이 없어 `appearance.json`에 `icon`을 넣지 않았습니다 |
