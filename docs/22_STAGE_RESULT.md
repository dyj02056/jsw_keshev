# 13~21단계 결과 표 (현재 제출본 = 이 문서를 포함한 커밋)

이 문서는 `docs/22_REPRODUCTION.md`의 재현 기록과 함께 읽는 **단계별 결과 표**입니다. 22단계 요구사항(누적 원문 일관성·이동 가능한 구성·재현 기록·시연/학생 진술 구분·버전/지원 범위)에 따라, 13~21단계 각 항목을 "모의 데이터(demo) 성공"과 "실제 연결 성공"으로 구분해 적습니다. **"미확인"과 "학생 구현 미완료"를 구분합니다.**

- 현재 코드 검토 기준 커밋: 이 문서를 포함한 커밋(branch `main`). 40자리 해시는 과제 화면 입력값과 `git rev-parse HEAD`로 대조하며, 부모 커밋은 `81b17bad0fc3cc351a8f9e24453a0a3a7d6549a4`입니다.
- 과거 화면 재현 대상: `005f53932823d9fa11e7415b96e4a7c9324fcc2d` (학생 진술; 기준 커밋에서 다시 실행하지 않음)
- 변경 관계: 부모 `81b17ba…` 이후 문서 5개, `005f539…` 이후 문서만 변경됨. 앱 코드·패키지 파일은 동일함. 상세는 `docs/22_REPRODUCTION.md` 0장.
- 기준 버전(이전 제출 문서 작성 시점): `alekov-client-starter@0.2.11`; 현재 작업 폴더: `alekov-client-starter@0.2.21` (package.json)
- 진술 주체: 학생(이 문서 작성자). AI 원문 검토는 실행 성공 증명이 아닙니다.
- 표시 규칙:
  - `demo` = 예제 데이터(demo) 응답. 실제 연결 성공 아님.
  - `실연결` = 실제 SDP 엔진/AI 게이트 연결. 기본 실행에서는 나오지 않음.
  - `미구현` = 학생 구현이 아직 없음(대기 문구만 반환 등). 제공 UI가 대신 계산하지 않음.
  - `미확인` = 이번 재현에서 직접 확인하지 못한 항목(실행 미실시 등).
  - `해당없음` = 이 단계 범위가 아님.

## 이 표를 읽는 방법

- **"미구현"은 학생이 그 기능을 아직 만들지 않은 상태입니다.** 제공 화면의 기능이 동작해도 학생 구현 완료로 계산하지 않습니다. 16단계 `renderStatus`는 코드 상 구현되었습니다.
- **"미확인"은 이번 22단계 재현에서 직접 실행해 확인하지 못한 항목**이며, 실패와 다릅니다. `docs/22_REPRODUCTION.md`의 미확인 사항과 짝을 이룹니다.
- `demo` 결과는 "예제 데이터"이며 실제 연결 성공이 아닙니다.
- 이 표의 결과는 **학생 진술**이며 서버의 실행 검증이 아닙니다.
- 19단계 실집행(실제 원천 조치 연결)은 현재 미준비 상태로, `docs/FINAL_PRODUCT_GUIDE.md` 5·9장과 일치합니다.

이 보완은 기존 제공 `src/pc-status.mjs`의 로컬 읽기 기능을 재사용합니다. CPU·메모리·디스크·네트워크 요약·Windows 방화벽·최근 Windows 기록을 학생이 새로 수집하는 코드는 추가하지 않습니다. 학생 구현은 성공한 최근 두 번의 로컬 조회를 사용률 퍼센트포인트로 비교하고, 사용자가 직접 다시 조회하도록 합니다.

| 요구 | 제공 기능 | 학생 추가 | 상태/근거 |
|---|---|---|---|
| CPU·메모리·디스크 현재값과 시각 | `src/pc-status.mjs`, `public/pc-status-view.mjs` | 상단 카드 요약 | 구현 후 직접 확인 결과는 아래 업데이트 |
| 네트워크·방화벽 | 비식별 네트워크 구성 요약, 세 방화벽 프로필 읽기 | 화면 요약 | 설정 변경·관리자 권한 상승 없음 |
| Windows 최근 경고·오류 | System·Application 최근 24시간, 5,000건 상한 | 기록 패널에서 구분 표시 | 건수는 공격/침해 탐지 결과가 아님 |
| 추이 비교 | 제공 조회 응답의 측정값 | 성공 조회 최근 12회 표 및 수동 비교 | 현재 화면 메모리만 사용, 실패/예시 제외 |
| SDP 연결 | 별도 엔진 연결 상태 | `SDP 미연결` 표기 | PC 조회 성공과 서로 대체하지 않음 |

직접 확인하지 않은 항목은 실행 증거로 주장하지 않습니다. 재현 절차는 `docs/STUDENT_RUNBOOK.md` 11장과 `docs/22_REPRODUCTION.md`의 PC 대시보드 기록을 따릅니다.
